# Curadoria de Fontes

Este diretório contém as fontes de dados utilizadas para alimentar e treinar o caderno do NotebookLM sobre Gestão Financeira Escolar e Cobrança.

## Fontes Selecionadas
*Utilize de 3 a 5 fontes abertas (PDFs, links ou textos) relevantes.*

1. **[fonte-01-legislacao-inadimplencia.txt](./fonte-01-legislacao-inadimplencia.txt)**
   - **Descrição:** Regulamentação brasileira sobre cobrança de juros e multas de mensalidades escolares, com base no CDC e na Lei nº 9.870/1999.
   - **Formato:** Texto (.txt) / Documento Técnico
   - **Uso no NotebookLM:** Forneceu as bases legais para os limites de multa moratória (2%) e as proibições de sanções pedagógicas a alunos inadimplentes.

2. **[fonte-02-aging-list-regua.txt](./fonte-02-aging-list-regua.txt)**
   - **Descrição:** Guia de boas práticas de gestão financeira e modelagem para escolas utilizando Aging List e Réguas de Cobrança automatizadas.
   - **Formato:** Texto (.txt) / Documento Financeiro
   - **Uso no NotebookLM:** Forneceu as bases conceituais para segmentação de devedores por tempo de atraso e o fluxo cronológico de alertas.

3. **[fonte-03-logica-calculo-modelo.txt](./fonte-03-logica-calculo-modelo.txt)**
   - **Descrição:** Lógica matemática de juros diários pro rata die, fórmulas estruturadas, diagrama de modelagem de banco de dados e algoritmo em pseudocódigo.
   - **Formato:** Texto (.txt) / Documento de Lógica e Engenharia de Dados
   - **Uso no NotebookLM:** Forneceu a lógica computacional exata para que a IA possa interpretar e validar os cenários de cálculo matemático de atraso.
